# GTO 德州扑克训练器 v2

德州扑克 GTO 学习与好友对战工具：**双层 CFR 求解**（翻前 169 手牌抽象预解 + 翻后单挑逐街 CFR+）、全牌局训练、数据统计与弱点分析。React + Vite + TypeScript；训练功能在浏览器运行，好友对战使用 Cloudflare 房间服务。

## 功能

- **好友对战**：2–9 人房间，可选现金桌或单桌锦标赛，邀请链接/房间码加入，真人与电脑混合对局、观战、聊天和中英切换；支持完整多人牌局、刷新恢复和可配置的行动时间。电脑为启发式练习对手。
- **训练器**：2-9 人桌全牌局训练。翻前多人（机器人按预解均衡策略采样行动），恰好单挑进翻后时逐街在 Web Worker 中现场求解（翻牌 ~2s / 转牌 ~7s / 河牌 <1s），每个决策即时判分（GTO 频率 + EV 损失），牌局结算并入库。多人进翻后则只评翻前（本工具暂不求解多人翻后策略）。支持只练翻前模式。
- **求解器**：翻后单挑轮次起点的 CFR 求解——选择场景、公共牌并点选双方范围；默认 6 人桌 BTN 开局、BB 跟注，自动填入底池和有效筹码。精细（33%/75%/全下，转牌约 1 分钟）或快速预设，结果以 13×13 矩阵展示，可沿动作树导航。分析参数变化时取消旧任务并清空旧结果。
- **范围表**：2-9 人桌全部翻前场景（首入/面对开局/面对 3-bet/面对 4-bet，6-max 约 50 个、9-max 约 100 个节点），来自构建期预解的 artifact。场景分类采用单项展开的折叠面板，默认打开「面对开局加注」；可再次点击收起，切换分类同步选择该分类的范围。
- **权益计算**：点选指定手牌或范围，计算两人的平均摊牌底池份额（5 万次蒙特卡洛），不直接提供下注建议。与求解器共用场景预设和范围矩阵，无须手工输入范围记法。
- **数据统计**：牌局历史（IndexedDB），任意时间段的 VPIP/PFR/3-bet/弃于3-bet/C-bet/BB防守/BTN偷盲/河牌跟注/WTSD 等指标——每项都与**同样本 GTO 基线**对比（同样的局面下 solver 会怎么打），9 个弱点检测器给出中文改进建议（≥30 手激活）。

## 求解架构

- **翻前**：向量 CFR+（regret-matching+，线性平均），169 手牌抽象；动作阶梯 2.5bb 开局（SB 3bb）/3-bet/4-bet/5-bet 全下，无 limp；面对 3-bet 只有盲注可冷跟（无冷 4-bet），其它未投入者只能弃牌；叶子估值 = 169×169 预计算权益矩阵 × 权益锐化（γ=1.6）× 位置实现系数；多人叶按两两权益乘积分配底池，份额逐手牌有界（自己 / (自己 + 其他人的范围均值)）。8 个桌型构建期预解并入库（`public/solutions/*.bin.gz`，共 ~650KB），HU 可利用度 <0.25bb/100。
- **翻后**：1326 组合向量 CFR+，河牌精确（排序牌力扫描 O(M) 摊牌评估 + 阻断牌容斥）；转牌全枚举 48 张河牌（河牌子树用粗化 continuation）；翻牌深度受限（发完热权益 × 实现系数，runout 采样）。跑在 Web Worker，支持进度与取消。
- 已知近似：多人 CFR 无纳什保证、翻前叶子模型是启发式、翻牌层较粗（靠逐街重解弥补）。定位是学习工具，精度不及商用 solver。

## 范围选择与复盘

- 场景采用本项目 2–9 人、100 BB 翻前预解，沿完整行动路径累计频率。13×13 矩阵支持点击、鼠标拖选、键盘方向键与空格、清空、全选和权重调整；显示范围占比及已知牌阻挡后的有效组合数。
- 底层保存 1,326 个具体组合的权重。修改一个手牌类别不会改动其他类别的花色权重。折叠的高级导入支持 `22+`、`A2s+`、`AsKs:0.5` 等记法，明确替换整个范围；后写的权重覆盖前面的设置。
- 训练历史、房间已结束牌局和本机对战历史提供「复盘」入口。选择翻牌、转牌或河牌的轮次起点，仅带入当时已出现的公共牌。新训练记录保存当时双方完整范围；本人手牌可用于权益计算或定位求解策略。
- 对战记录根据该手初始筹码、盲注和公开行动还原底池及有效筹码，分析金额统一为该手 BB。只有翻前路径严格匹配预解时才自动生成「推定」范围；转牌、河牌的推定范围未按翻后行动收窄。无法匹配时可点选范围预设。
- 求解复盘限双方仍可行动、没有第三方底池权益的真正单挑局面。多人局面只能做选定两人的权益对比；锦标赛仅分析筹码价值，不提供 ICM。缺少必要信息的旧记录显示原因并允许导入已有牌面，不猜测筹码或范围。
- IndexedDB 保留本人参与且已结束的最近 1,000 手对战明细，按房间实例、本人身份和手号去重，仅保存公开信息和本人手牌。淘汰明细不减少累计统计；服务器仍只保留房间最近 50 手。本机记录显示估算占用，存储失败会提示并退回本页内存，不支持跨设备同步。

## 重新生成求解数据（改了 solver 参数后）

```bash
npx tsx scripts/gen-equity169.ts 100000   # 169×169 权益矩阵（~5 分钟）
npx tsx scripts/solve-preflop.ts          # 预解 2-9 人桌，8 个桌型并行子进程（~14 分钟，取决于 9 人桌）
npx tsx scripts/solve-preflop.ts 6        # 只解某个桌型（本进程）
```

## 好友对战

独立的「好友对战」页支持邀请链接、8 位房间码、真人与电脑混合对局。电脑基于自身手牌、公共牌和估算权益行动。

### 创建房间和牌桌模式

- 人数选择 2–9 人，初始筹码通过下拉框选择 50 / 100 / 200 / 300 / 500 / 1000 BB，默认 100 BB。行动时间可选 20 / 30 / 40 / 50 / 60 秒，默认 30 秒。
- **现金桌**：盲注固定为 0.5 / 1 BB，下注最小单位为 0.5 BB。每手保留结算后的筹码，补码恢复到房间初始筹码量。
- **单桌锦标赛**：初始盲注为 0.5 / 1，升盲间隔默认 10 分钟，可设为 1–60 分钟的整数。计时到期后，从下一手开始使用新的盲注，本手下注与结算不变。桌面上的筹码、底池和下注金额始终使用固定「筹码 / chips」单位，不随升盲重新缩放。
- 锦标赛支持延迟报名与重购期。建房时的 `registrationRaises` 可设为升盲 0–10 次后截止，默认 3 次；设为 0 则开赛即截止。升盲间隔默认 10 分钟。
- 报名与重购截止前，新玩家可选择空席报名，从下一手起参加；输光的真人可重购初始筹码量，电脑输光后自动重购。开放期即使只剩一名有筹码的玩家，也不会提前宣布冠军。
- 截止后禁止新参赛和重购，电脑也不再自动补码；输光者淘汰，最后剩余一名参赛者获冠军并停止发牌。报名截止前后均允许加入观战和聊天。
- 已参赛玩家不能换位、站起或被移除。主动退出的参赛者先结算当前手，再按弃赛处理，不能重新报名；刷新恢复尚未弃赛的原参赛身份不视为重新报名。
- 锦标赛展示名次、淘汰和冠军状态；个人统计中的净赢 BB 与 BB/100 按每手实际大盲归一，和桌面显示的固定筹码数区分。

### 席位、观战和入场

以下动态换座、入场与补码规则适用于现金桌；锦标赛按上面的延迟报名、重购截止和固定参赛席位规则执行。

- 加入房间先进入观战，满桌和牌局进行中均可加入、聊天；可以选择空位或电脑位。正在进行时预约座位，结算后落座并替换电脑。可在预约座位或房间设置中取消预约；取消换座会保留原座位、筹码及原入场资格。
- 房主可直接在空座添加电脑、在电脑位移除电脑；本手进行中的增删在结算后生效，不影响本手行动。尚未入场的电脑可以取消添加，待移除的电脑位可以预约接替。电脑编号在同房间历史中不重用。
- 首手开局前入座的人正常参与；开局后的新入座或换座玩家，默认等自然大盲，也可选择支付 1 BB 自愿盲注，从下一手参与。自愿盲注计入本轮已下注额，不计入 VPIP；如果正好是大盲不重复扣款。缩桌只剩一位老玩家时，以新玩家在大盲位置组成单挑桌；全部席位都在等盲时，至少一人需选择支付 1 BB。
- 输光的真人默认保留座位观战，可补码继续，或选择「站起观战」腾出位置。有筹码的玩家也可以站起，再选择空位坐下；筹码保留。电脑输光后自动补码。
- 观战者可申请增加席位；房主可主动增加或响应申请，上限 9 席。
- 真人可选择将实时底牌公开给观战者，默认关闭；电脑没有实时底牌分享。本手仍是对手的玩家，即使已经弃牌或站起，也不会因此看到对手分享的牌。正常摊牌和全下后停止下注时的公开展示规则见下文。

### 行动、结算和展示

- 翻前首次加注提供 2/3/4/5 BB 和全下；翻后提供 1/3、1/2、3/4、满池和全下，也可自定义合法金额。轮到自己且允许加注时，金额输入、快捷选项和滑块直接显示；调整金额不会下注，点击最终的下注／加注按钮或在金额输入框按回车才提交。支持未跟注筹码退回、多人边池、平分和短筹码全下。
- 行动时间使用建房时选择的 20 / 30 / 40 / 50 / 60 秒（默认 30 秒），超时可过牌则过牌，否则弃牌。每人初始 3 张加时卡，每张加 30 秒，在房间累计每小时再获得 1 张。
- 房主开始首手后自动连续发牌；未摊牌结束后等待 3 秒，摊牌发 1 次等待 5 秒，跑 2 次等待 7 秒，跑 3 次等待 10 秒，再自动下一手。倒计时从完整结算后开始；没有足够玩家或在线真人时暂停。补码或重新入座使暂停的牌桌恢复后，采用独立的 3 秒开局倒计时。
- 所有后续下注结束、需要发完公共牌时，仍在争夺底池的真人可选发 1/2/3 次，以最低选择为准；15 秒未选按 1 次。各牌面分别分配主池和边池，共享已经发出的公共牌。
- 全下投票结束后逐轮展示公共牌：服务端每 900 毫秒揭开一张尚未发出的牌，每轮完成后展示获池者和该轮派彩 2.4 秒，再开始下一轮。已发出的公共牌保持不变；当前未完成的轮次不会提前公开后续牌面或结果。全部轮次播放完成后统一记账，再按发牌次数开始 5 / 7 / 10 秒的下一手倒计时；刷新和房间服务重启会保留当前进度与截止时刻。
- 只剩电脑需要行动时可加速剩余行动；真人仍需选择发牌次数时停在投票阶段，也不会跳过逐张发牌和逐轮结果展示。
- 真人手后可公开一张或两张底牌；正常摊牌时未弃牌者公开双牌，电脑手后自动公开。全下发牌展示开始时，仍在争夺底池的手牌向全桌公开，已弃牌的真人底牌仍按原权限隐藏。自己的底牌在弃牌后仍可查看。每轮完整牌面展示后，在未弃牌的摊牌者座位显示最佳五张的牌型；切换已完成的跑牌轮次时同步更新，不显示隐藏或不完整牌面的牌型。

### 界面、记录和声音

- 对战、训练器、求解器、范围表、权益计算与数据统计采用统一的深色、浅绿色界面；行动及策略热力图仍保留有含义的颜色。模型说明可在页脚展开。
- 对战牌桌与行动区按可用视口高度分配空间；行动区在等待、行动、跑牌投票和手后结算时保持同一高度，避免牌桌跳动。等待时显示自己的底牌、剩余筹码与本轮投入；下注金额与快捷选项直接显示。记录和聊天在各自面板内滚动。
- 训练器使用独立的紧凑座位卡，显示头像、位置、剩余筹码和行动状态；自己固定在底部正中，下注筹码置于桌内。阶段位于独立信息栏，公共牌和底池居中；弃牌状态清晰区分，自己的底牌仍保留。适配 2–9 人桌，不改变训练引擎与求解流程。
- 空座、电脑位及预约座位按当前模式提供可用操作；点击玩家座位或头像查看本场数据及更多操作，房间设置提供共享底牌及当前模式允许的站起、扩桌等选项。下注筹码显示在桌内，弃牌状态明确区分；入座后将自己旋转到视角底部正中，每位参战玩家有 BTN、SB、BB、UTG 等位置标签。
- 「记录／房间玩家／聊天」面板可收起，底部入口可随时打开；桌面默认展开，较窄屏幕默认收起并使用覆盖面板，保留行动区。聊天有未读提示，查看聊天后清除；房间玩家显示坐着、站着或离开等状态，头像数据包含当前筹码。
- 新聊天会在发言玩家旁显示气泡，支持文字、Emoji 和筹码表情，每位玩家保留最新一条并在约 7 秒后消失。房间设置中的「在牌桌上显示玩家聊天」默认开启，偏好保存在本机；回到页面、重连或重新开启不会重播旧消息。完整消息仍可在聊天面板查看。
- 开始对战前，房主可点击「开始对战」下方的「空位补齐电脑」一次填满空席，保留现有玩家；开局后不再提供一键补齐。
- 记录面板可切换本手及本房间最近 50 手已完成牌局，按翻前、翻牌、转牌、河牌分段展示公共牌与行动；3-bet／4-bet 等名称与牌桌一致，标注全下，区分加注至本轮总额与本次跟注投入。自己的行动高亮，结算显示派彩及各玩家净盈亏。
- 本手记录默认自动跟随最新行动；向上滚动时暂停，点击「回到最新行动」恢复。历史阅读不会被新行动打断。
- 记录顶部展示自己的底牌和位置。新完成牌局的底牌仅向持有原访问凭证的本人返回，刷新与服务器重启后保留；观战者和仅凭同名重新加入的人不会获得历史私牌。旧版本未保存的底牌显示缺失提示。历史按手号去重，最多 50 手，随房间销毁清除。
- 规则介绍包含牌局规则、用纸牌示例展示的牌型大小和术语解释。训练器、求解器、范围表、权益计算、对战和数据统计均支持中英切换；切换语言保留当前页面状态。好友对战位于导航最后。
- 背景音乐使用随应用打包的完整录音，可在声音设置中选择曲目。应用首次交互后按浏览器权限启用，音乐按完整曲目重复播放，保留自然淡出；游戏音效由 Web Audio 合成。曲目、来源、授权和转码信息见 [音频说明](public/audio/README.md)，应用声音设置中也有署名和授权链接。
- 声音控制位于应用顶部，扬声器按钮一键静音／恢复，旁边小箭头打开选曲、音乐与音效音量等完整配置，偏好保存在浏览器。切换训练器、范围表等应用内页面时音乐连续播放；浏览器标签页隐藏时暂停，回来后不补播旧行动。
- 留在房间并切到其他应用内页面时，房间继续同步；轮到自己行动会显示倒计时提醒和返回牌桌入口，并按音效设置播放提醒。全下显示短暂筹码动画，并遵循系统减少动态效果设置。

### 身份和数据

- 昵称即公开身份，只需输入一次，支持 1–16 个可见字符（包括中文）。昵称经去除首尾空格、NFKC 规范化并忽略大小写后在房间内唯一；正在使用的昵称不可重复加入。离场后用同一昵称恢复原记录、筹码和统计，离线超过 60 秒也可重新进入。访问凭证仍独立随机生成，重新进入者不能接管旧手行动或看到其未公开底牌。
- 点击头像查看本桌 VPIP、PFR、3-bet、C-bet、AF、WTSD、W$SD 与净赢等统计。对战统计与训练器 GTO 决策评分分开，自己的对战统计保存在当前浏览器的「数据统计」中。
- 「我的对战数据」提供清空历史入口，需在应用内确认；同时清空本浏览器的个人对战累计与本机复盘明细，不影响房间内统计或训练器历史。按房间实例和玩家保留统计基线与复盘清除水位，之后仅累计新完成的手牌；同一手的更新、下一轮轮询、重新加载和其他标签页的旧数据不会重新导入已清空历史。存储不可用时显示提示，当前页面保留内存记录。
- 刷新同一标签页可恢复身份；访问凭证保存在 `sessionStorage`，不同标签页可测试不同玩家。房主离开立即交接；房主离线超过 60 秒后由在线真人接任。
- 服务端持有完整牌堆和底牌，按身份及公开设置裁剪响应；房间约每秒同步。闲置 24 小时过期，最后一位真人主动离开时销毁房间，同一昵称不能恢复已销毁房间的数据。离场者未结算的个人成绩通过只读回执补入本机统计，房间销毁后的个人回执最多保留 120 秒。

### 本地联机运行

```bash
npm install
npm run dev:battle  # 构建前端并启动完整房间服务：http://localhost:8787
```

需要前端热更新时，保持以上服务运行，在另一终端启动 `npm run dev`；Vite 会将 `/api` 代理到本地 8787 端口。`npm run preview` 仅提供静态预览，不能单独提供好友房间。

在两个独立浏览器标签页分别创建、加入同一房间，可验证真人对战。跨设备使用需要所有设备都能访问同一个服务地址；`localhost` 邀请链接仅用于本机测试。

### 服务端与部署

使用 Cloudflare Worker + SQLite-backed Durable Object，每个房间拥有独立、持久化且串行处理的状态；Durable Object alarm 驱动电脑和超时行动。无需额外数据库密钥。API 的房间身份使用独立随机 bearer token；分享链接只含房间码。

```bash
npm run build            # 同时检查前后端 TypeScript
npm run test:battle      # 规则、结算、隐私与随机完整牌局回归
npm run test:battle:api  # 隔离 HTTP/时钟测试，含顺序发牌、历史隐私、预约取消与状态恢复
npm run test:battle:stats # 统计口径、清空基线、旧数据迁移与跨标签同步
npm run test:battle:room  # 入场、身份、隐私和离场回执的独立回归
npm run test:battle:presentation # 位置标签与中英电脑名
npm run test:battle:audio # 全局音频、手势启用、音量、静音与异步恢复竞态
BATTLE_BASE_URL=http://localhost:8787 npm run test:battle:api # 可选：真实本地服务检查
BATTLE_TEST_PERSISTENCE=1 npm run test:battle:api  # 加测独立本地 Worker 重启后的牌局恢复
npm run deploy           # 构建并发布，应用 wrangler.jsonc 的房间迁移
```

部署需要有目标 Cloudflare Worker 的授权。`wrangler.jsonc` 已增加 `ROOMS` 绑定和 `v1-battle-rooms` SQLite migration；后续部署保留这条迁移。接口路径优先经过 Worker，其余页面继续由静态资产提供。实现参考 [Durable Objects 存储文档](https://developers.cloudflare.com/durable-objects/best-practices/access-durable-objects-storage/) 和 [静态资产路由文档](https://developers.cloudflare.com/workers/static-assets/routing/worker-script/)。
